# 介紹
Pterodactyl 是一套採用 PHP、React 與 Go 建置的開源遊戲伺服器管理面板。Pterodactyl 以安全性為設計核心，
將所有遊戲伺服器執行於隔離的 Docker 容器中，同時為管理員與使用者提供美觀且直覺的使用者介面。還在等什麼？
立即讓遊戲伺服器成為你平台上的一等公民。

## 支援的遊戲
我們利用 Docker 容器隔離每個遊戲執行個體，因此支援大量不同的遊戲。你可以在世界各地託管遊戲，
不必為每台實體機器安裝一堆額外相依套件。

我們核心支援的遊戲包括：

* Minecraft — including Spigot, Sponge, Bungeecord, Waterfall, and more
* Rust
* Terraria
* Teamspeak
* Mumble
* Team Fortress 2
* Counter Strike: Global Offensive
* Garry's Mod
* ARK: Survival Evolved

除了標準支援的遊戲 Nest 之外，社群也持續拓展這套軟體的可能性，並提供許多其他遊戲。以下是其中一些：

* Factorio
* San Andreas: MP
* Pocketmine MP
* Squad
* FiveM
* Xonotic
* Discord ATLBot
* [and many more...](https://pterodactyleggs.com)

## 負責任的漏洞揭露
Pterodactyl 完全開源，因此歡迎獨立使用者與稽核人員檢視我們的程式碼並尋找安全性問題。如果你發現任何可疑之處，
請直接聯絡 `support@pterodactyl.io`。揭露安全性問題時，請採取負責任的方式，_不要_ 將問題回報到公開的錯誤追蹤系統。

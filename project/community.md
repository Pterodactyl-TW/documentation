Pterodactyl 從 2015 年由數十人組成的社群，發展至如今擁有數千名成員的社群。在這段期間，我們經歷了無數成長過程中的陣痛，社群也在各方面產生了許多變化。然而，Pterodactyl 的核心宗旨始終不變：成為執行遊戲伺服器的**首選平台**。

為了堅守這個目標，並持續培養其中一個規模最大的開源遊戲控制面板社群，我們制定了一套簡單的社群參與規範。這些規範旨在建立一個包容且歡迎新使用者的環境，讓數千名現有使用者、管理員、網路擁有者與主機代管公司能夠共存。

這些規則與規範適用於 Pterodactyl 社群的所有層面，包括但不限於官方 Discord 伺服器、GitHub 組織中的所有活動，**以及我們 Pterodactyl-TW 的繁體中文 Discord 社群**。

## 關於我們的台灣 Discord 社群

除了官方英文社群之外，Pterodactyl-TW 也維護一個獨立的繁體中文 [Discord 社群](https://pterodactyl.tw/discord)，適合下列情況的使用者加入：

- 想以中文詢問 Panel、Wings 或 Egg 相關的架設與使用問題
- 想回報本站文件翻譯上的錯誤，或提出改善建議
- 想加入我們的繁體中文化服務團隊，一起維護這個網站
- 想單純認識其他使用繁體中文的 Pterodactyl 使用者

我們的社群同樣適用本頁下方的所有社群規範；此外還有幾點補充：

- 這裡不是官方支援管道，我們是志願性質的社群翻譯團隊，無法保證能解決所有官方軟體本身的問題。若遇到我們也無法排解的狀況，可能會建議你改到官方 Discord 或 GitHub Issues 詢問。
- 歡迎在這裡使用中文交流，但請保持基本禮貌，規範與下方「保持成熟」等章節完全相同，不會因為使用中文而有例外。
- 若你發現文件中有翻譯錯誤、用詞不一致，或內容已過時，非常歡迎直接在社群中提出，或依照[首頁](/)的說明開 Pull Request。

## 社群規範

最基本而言，這些規範可以歸納為：

1. 做一個正派的人。
2. 耐心是一種美德。

### 保持成熟

你應保持成熟，並以符合基本人道與禮儀的方式控制自己的行為。如果你無法做到，將會被移出社群。禁止人身攻擊、垃圾訊息（任何形式）、「人肉搜尋」或其他失控行為。

本社群對語言內容的管理相對寬鬆。不過，以下是絕對**不會被容忍**的行為，違者將被移出社群：

- 種族歧視、性別歧視、恐同、恐跨，或其他貶抑性言論、圖片、暗示，以及任何唯一目的在於侮辱個人、組織或特定群體的語言。
- 對任何個人、群體或組織發出暴力威脅，包括對這些對象進行「人肉搜尋」。
- 色情或過度暴力的內容。

### 避免製造爭端

禁止進行旨在損害其他公司或使用者形象的討論，包括連結至或討論相關網站或軟體。這包括公開指責使用破解軟體的主機商、試圖引發他人對服務或網站的負面反應，或以其他方式煽動爭端。

::: tip 提示
回應他人時，請假設對方是出於善意。你不必同意每個人的看法，也不需要對所有事情作出回應。
:::

### 保持耐心

這是一個開源專案。開發團隊中沒有任何成員以正式職務受薪來編寫、維護或支援本軟體；我們繁體中文化團隊同樣也是完全志願性質。以下行為在本社群中不受鼓勵：

- 在短時間內於同一頻道（或不同頻道）重複提出相同問題。
  - 有些問題被忽略是可以理解的。如果經過合理時間後，你的問題仍未獲得回覆，歡迎重新發表。
- 所有支援問題都應留在支援頻道的範圍內。
- 不要僅為了要求他人前往支援頻道查看並協助你，而中斷非支援頻道中的討論。

### 禁止商業服務

除非另有註明，嚴格禁止討論付費安裝／升級服務、修改服務或任何其他商業方案。這也包括在未獲對方要求的情況下，透過私人訊息聯絡個人並提供服務。

::: warning 檢查你的使用者名稱
禁止在 Discord 的使用者名稱或顯示名稱中宣傳商業服務。
:::

官方社群中，銀級及以上的[贊助者](/project/about.html#贊助者)不受此規定限制。

### 禁止提及或標記洗版

請勿在未事先徵得同意的情況下，直接傳送私人訊息給管理員、開發人員或重要社群成員。除非對方明確要求，否則所有支援問題都應留在公開支援頻道中。

_但是，如果我想回覆某個人呢？_ 這沒有問題！我們只是希望你不要直接提及尚未參與該討論的人。

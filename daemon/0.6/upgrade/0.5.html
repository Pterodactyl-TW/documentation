# 升級 0.5 系列

此軟體已遭棄用

本文件適用於已遭棄用的軟體，不再提供任何安全性更新或社群支援。 基於歷史原因，本文件仍保留供查閱。

在正式環境中，你應搭配 Pterodactyl Panel 1.0 安裝並使用 Wings。

提示

這次升級其實相當輕鬆，得益於 Docker，伺服器在整個流程中都不會離線，使用者只會在重新啟動的短短瞬間，暫時失去與 Panel 及 Daemon 的連線而已。

# 下載最新發行版本

開始之前，先確認你目前位於 Daemon 目錄 /srv/daemon。確認無誤後，執行下方命令，下載最新檔案並直接解壓縮至 Daemon 目錄。

curl -L https://github.com/pterodactyl/daemon/releases/download/v0.5.7/daemon.tar.gz | tar --strip-components=1 -xzv

# 更新元件

下載完成後，最後一步只要執行下方命令，更新元件並重新啟動 Daemon，整個升級就完成了。

npm update --only=production
systemctl restart wings

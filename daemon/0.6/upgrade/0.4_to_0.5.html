# 從 0.4.X 升級至 0.5.X

此軟體已停止維護

本文件適用於已停止維護的軟體，該軟體不再取得任何安全性更新，也不再獲得社群支援。本文件僅因歷史原因而繼續保留。

在正式環境中，您應安裝並使用 Wings 以及 Pterodactyl 控制面板 1.0。

  • Docker 調整
  • 下載檔案
  • 清理 SFTP
  • 檔案遷移
    • 重新建置容器

DANGER

此升級流程會要求透過 Daemon 執行的所有伺服器暫時離線，因為系統需要重新整理資料並重新建置伺服器容器。請提前安排好維護時間。

您也需要先將控制面板更新至 0.7.X 系列，才能完成此升級流程。

# Docker 調整

過去，我們曾在安裝說明中提供快速安裝 Docker 的指令碼。但我們犯了一個令人遺憾的錯誤，沒有深入檢查該指令碼，因而忽略了它會啟用 Docker 的 Edge 測試版套件來源。您應參閱 Docker 官方文件，將套件來源切換至穩定版本通道。

請參閱 Docker 官方文件，了解如何在伺服器上安裝 Docker CE。以下列出幾個常見支援系統的快速連結：

  • Ubuntu (opens new window)
  • CentOS (opens new window)
  • Debian (opens new window)

# 下載檔案

若要從 v0.4.X 升級，請先切換到安裝 Daemon 的目錄。如果您是依照安裝指南操作，Daemon 很可能位於 /srv/daemon。接著使用以下指令下載並解壓縮套件：

curl -L https://github.com/pterodactyl/daemon/releases/download/v0.5.7/daemon.tar.gz | tar --strip-components=1 -xzv

然後執行以下指令，更新 Daemon 的核心相依套件：

npm update --only=production

# 清理 SFTP

此版本的 Daemon 內建 SFTP 子系統，不再需要特殊的 Docker 容器，也不會再遇到令人困惑的檔案權限問題。Daemon 大多可以自行處理相關內部變更，您只需要移除舊的 SFTP Docker 容器。

請執行以下指令。如果您使用的是不同的連接埠，請將 2022 替換成實際使用的連接埠：

docker rmi -f quay.io/pterodactyl/scrappy
sudo kill $( sudo lsof -i:2022 -t )

完成上述步驟後，您需要啟動 Daemon，讓系統自動建立新的系統使用者。請在 Daemon 目錄中執行 sudo npm start。建議以前景模式執行，以便監控進度並確認執行過程沒有問題。Daemon 完成啟動並正常運作後，請使用 CTRL+C 將其停止。

如果您因任何原因需要將使用者名稱設定為 pterodactyl 以外的名稱，可以在啟動 Daemon 前修改 core.json，設定 docker.container.username 項目。99.9% 的使用者不需要變更此使用者名稱。

# 檔案遷移

接下來是升級過程中最耗時的部分：資料遷移。從 v0.4.X 升級至 v0.5.X 時，只需要執行一次資料遷移。

進行此遷移時，您必須先停止所有伺服器。所有伺服器的容器也需要重新建置；由於還需要將一些新資料更新至伺服器設定，因此這項工作會透過控制面板中的主控台指令完成。我們會在完成所有資料遷移後執行該指令。

若要執行遷移，請在 Daemon 目錄中執行以下指令，並依照提示操作。請注意，這可能需要幾分鐘，尤其是在資料量很大的情況下。

sudo npm run migrate
docker system prune

# 重新建置容器

完成資料遷移後，您還需要在控制面板上執行指令，更新這些伺服器的所有設定。首先，請確認 Daemon 以前景模式啟動（sudo npm start）。接著，在控制面板目錄中執行以下指令，不要在 Daemon 目錄中執行：

php artisan p:server:rebuild --node=###

將上方的 ### 替換為正在更新之節點的 ID。此指令會將所有伺服器標記為需要重新建置，並將最新資訊寫入其設定檔。完成後，請停止 Daemon，執行以下指令，然後再次啟動 Daemon。如果您希望同時更新所有正在執行的 Daemon，請移除 --node 參數。

最後一次以前景模式啟動 Daemon，確認執行過程沒有錯誤。接著停止 Daemon，並使用以下服務指令重新啟動：

sudo systemctl start wings

謝謝！

全部完成！感謝您的耐心。此次更新修正了先前軟體實作中的許多問題，也為日後遷移至新版 Daemon 做好資料準備，而新版 Daemon 目前仍在開發中。

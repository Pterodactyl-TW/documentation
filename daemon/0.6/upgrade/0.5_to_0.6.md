# 從 0.5.X 升級至 0.6.X

::: danger 此軟體已遭棄用
本文件適用於**已遭棄用的軟體**，不再提供任何安全性更新或社群支援。
基於歷史原因，本文件仍保留供查閱。

在正式環境中，你應搭配 [Pterodactyl Panel 1.0](/panel/1.0/getting_started.md) 安裝並使用 [Wings](/wings/1.0/installing.md)。
:::

[[toc]]

::: warning 需要重新啟動伺服器
升級 Daemon 後必須重新啟動伺服器，才能在 Panel 中看到預期的記錄輸出。
:::

## 不相容變更
此版本對 Daemon 的運作方式引入幾項不相容變更，但仍與 Panel `v0.7.X` 相容，因此不需要更新 Panel。

此版本最重要的變更，是從自訂記錄功能改用 Docker 記錄功能。這能讓我們更完整地輸出附加至容器前發生的事件、集中處理邏輯，
並讓 Docker 管理記錄（它非常擅長這件事）。現在伺服器拒絕啟動時，不會只看到沒有前因的「Server has crashed」訊息，
而是能看到容器在此之前發生的_所有_輸出內容。

## 下載檔案
若要從 v0.5.X 升級，先切換至 Daemon 的安裝目錄。如果依照安裝指南操作，Daemon 通常位於 `/srv/daemon`。
接著使用下方命令下載並解壓縮壓縮檔。

::: danger
繼續前請停止 Daemon 程序，以避免問題並確保所有內容正常更新。
``` bash
systemctl stop wings
```
:::

``` bash
curl -L https://github.com/pterodactyl/daemon/releases/download/v0.6.13/daemon.tar.gz | tar --strip-components=1 -xzv
```

接著使用以下命令更新 Daemon 的核心相依套件。

``` bash
npm update --only=production
```

### 啟動 Daemon
最後啟動 Daemon，通常可使用下方命令。

``` bash
systemctl start wings
```

## 重建容器
由於我們對伺服器輸出顯示方式進行了底層變更，你需要重建並重新啟動所有伺服器。重建是必要步驟，重新啟動則是選擇性的，
但強烈建議執行，否則可能無法看到任何主控台輸出。

請_在 Panel 伺服器上_執行以下命令，進行大量重建與重新啟動。將 `###` 替換為剛升級節點的 ID，
或完全移除 `--node` 旗標，在所有節點上重建。

``` bash
php artisan p:server:rebuild --node=###
```

接著使用以下命令重新啟動所有伺服器，也可以在 Panel 中逐一手動重新啟動。

``` bash
php artisan p:server:bulk-power restart --nodes=###
```

# 升級 0.6 系列

::: danger 此軟體已遭棄用
本文件適用於**已遭棄用的軟體**，不再提供任何安全性更新或社群支援。
基於歷史原因，本文件仍保留供查閱。

在正式環境中，你應搭配 [Pterodactyl Panel 1.0](/panel/1.0/getting_started.md) 安裝並使用 [Wings](/wings/1.0/installing.md)。
:::

::: warning 僅適用於次版本升級
這裡要先提醒一下：**請勿**用本指南從 `0.5.X` 升級至 `0.6.X`，這樣做不會正常運作，之後還會踩到各種錯誤。如果你是要做這個跨版本升級，請改參閱[從 0.5 升級至 0.6](/daemon/upgrade/0.5_to_0.6.md)文件完成更新。
:::

::: tip
如果你確認自己是在 0.6 系列內升級，可以放心，得益於 Docker，伺服器在整個流程中都不會離線，使用者只會在重新啟動的短暫瞬間，暫時失去與 Panel 及 Daemon 的連線。
:::

## 下載最新發行版本
開始之前，先確認你目前位於 Daemon 目錄 `/srv/daemon`。確認無誤後，執行下方命令，下載最新檔案並直接解壓縮至 Daemon 目錄。

``` bash
curl -L https://github.com/pterodactyl/daemon/releases/download/v0.6.13/daemon.tar.gz | tar --strip-components=1 -xzv
```

## 更新元件
下載完成後，接著執行下方命令更新元件並重新啟動 Daemon。不過在動手之前，有兩件事要先留意一下：

::: warning 需要 Node.js 10
`0.6.13` 需要 Node.js v10 或更新版本，才能正確編譯 `mmmagic` 相依套件，所以請先確認你至少執行的是第 10 版。
可以執行 `node -v` 檢查目前版本，如果看到的是 `v6` 或 `v8`，就需要先升級 Node.js 才能繼續。
:::

::: warning 稽核結果
更新過程中，你可能會看到類似「found 14 vulnerabilities (6 low, 3 moderate, 5 high) in 927 scanned packages」這樣的輸出，這是正常現象，可以放心忽略。但切記**不要**執行 audit fix 命令，因為這麼做_一定會_破壞 Daemon。
:::

``` bash
npm install --only=production --no-audit --unsafe-perm
systemctl restart wings
```

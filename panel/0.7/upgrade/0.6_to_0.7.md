# 從 0.6 升級至 0.7

::: danger 此版本已終止支援
本文件適用於**已終止生命週期的軟體**，不再提供任何安全性更新或社群支援。
基於歷史原因，本文件仍保留供查閱。

在正式環境中，你應安裝並使用 [Pterodactyl Panel 1.0](/panel/1.0/getting_started.md)。
:::

## 取得更新檔案
更新流程的第一步是從 GitHub 下載新的 Panel 檔案。下方命令會下載最新 Pterodactyl 版本的發行壓縮檔，
並儲存到目前目錄。請先確認位於 `/var/www/pterodactyl`，因為下方命令會自動解壓縮到目前所在目錄。

``` bash
curl -L https://github.com/pterodactyl/panel/releases/download/v0.7.19/panel.tar.gz | tar --strip-components=1 -xzv
```

下載所有檔案後，需要為快取與儲存目錄設定正確權限，以避免網頁伺服器相關錯誤。

``` bash
chmod -R 755 storage/* bootstrap/cache
```

## 清除已編譯資源
舊版 Pterodactyl 曾嘗試快取設定檔，以提升速度與效能，但實際上只帶來更多麻煩，效能改善也很有限，因此我們停止了這項做法。
執行下方命令會清除快取檔案，讓我們可以繼續升級。

::: tip
從 `0.6.X` 升級時通常只需執行一次。升級完成後不會再快取設定檔，因此不需要再次移除任何內容。
:::

``` bash
rm -rf bootstrap/cache/*
```

移除設定快取後，需要清除範本快取，確保使用者取得最新範本。

``` bash
php artisan view:clear
```

## 更新相依套件
下載所有新檔案後，需要更新 Panel 的核心元件。請執行下方命令並依照提示操作。

``` bash
composer install --no-dev --optimize-autoloader
```

## 更新環境設定
這些指令會在方括號中顯示目前值。若要保留目前值，只要按 Enter，流程就會繼續且不會修改設定。

::: tip
我們已將建議的快取驅動程式從 Memcached 改為 Redis。如果目前使用 Memcached，仍可正常繼續使用，
但之後的安裝文件只會說明 Redis。
:::

``` bash
php artisan p:environment:setup
php artisan p:environment:mail
php artisan p:environment:database
```

## 更新資料庫

::: warning 備份資料庫
從 `0.6` 升級至 `v0.7` 包含相當重大的資料庫變更。雖然遷移工具能為你處理所有工作，仍建議在繼續前備份資料庫，以防萬一。
:::

::: warning
執行下方的 `db:seed` 會覆寫你對 Pterodactyl 核心 Nest、Egg 或 Egg 變數所做的任何變更！這是無法避免的，且必須執行此 Seeder。
為避免未來發生此情況，請建立自訂 Nest，或為遊戲變體建立自訂 Egg。
:::
``` bash
php artisan migrate --force
php artisan db:seed --force
```

## 清理 API 金鑰
0.7.0 引入重大變更，改變 API 金鑰的使用、儲存與驗證方式。因此，先前建立的所有金鑰都將無法繼續使用。
為了維持整潔，請移除這些孤立金鑰，執行下方命令即可。

``` bash
php artisan p:migration:clean-orphaned-keys
```

別忘了為自己建立新金鑰，也要通知所有使用者同樣建立新金鑰。

## 設定權限
The last step is to set the proper owner of the files to be the user that runs your webserver. In most cases this
is `www-data` but can vary from system to system &mdash; sometimes being `nginx`, `apache`, or even `nobody`.

``` bash
# If using NGINX or Apache (not on CentOS):
chown -R www-data:www-data * 

# If using NGINX on CentOS:
chown -R nginx:nginx *

# If using Apache on CentOS
chown -R apache:apache *
```

# 升級 0.7 系列

此版本已終止支援

本文件適用於已終止生命週期的軟體，不再提供任何安全性更新或社群支援。 基於歷史原因，本文件仍保留供查閱。

在正式環境中，你應安裝並使用 Pterodactyl Panel 1.0。

本文件說明 0.7.X 系列內的升級流程，例如從 0.7.3 升級至 0.7.11。請勿使用本指南從 0.6 升級或升級至 1.0。

WARNING

如果使用自訂主題，請注意升級會移除這些檔案。升級完成後必須重新上傳主題，否則可能導致伺服器錯誤。

# 取得更新檔案

更新流程的第一步是從 GitHub 下載新的 Panel 檔案。下方命令會下載最新 Pterodactyl 版本的發行壓縮檔，並儲存到目前目錄。 請先確認位於 /var/www/pterodactyl，因為下方命令會自動將壓縮檔解壓縮到目前資料夾。

curl -L https://github.com/pterodactyl/panel/releases/download/v0.7.19/panel.tar.gz | tar --strip-components=1 -xzv

下載所有檔案後，需要為快取與儲存目錄設定正確權限，以避免網頁伺服器相關錯誤。

chmod -R 755 storage/* bootstrap/cache

# 更新相依套件

下載所有新檔案後，需要更新 Panel 的核心元件。請執行下方命令並依照提示操作。

composer install --no-dev --optimize-autoloader

# 清除已編譯的範本快取

你也應清除已編譯的範本快取，以確保使用者能正確看到新的與已修改的範本。

php artisan view:clear
php artisan config:clear

# 更新資料庫

你也需要更新資料庫結構，以配合最新版本的 Pterodactyl。執行下方兩個命令會更新結構，確保隨附的預設 Egg 保持最新， 並加入可能新增的 Egg。請記住，絕對不要編輯我們隨附的核心 Egg！它們會在更新過程中被覆寫。

php artisan migrate --force
php artisan db:seed --force

# 設定權限

最後一步是將檔案擁有者設定為執行網頁伺服器的使用者。大多數情況下是 www-data，但可能依系統而異， 有時會是 nginx、apache，甚至是 nobody。

# If using NGINX or Apache (not on CentOS):
chown -R www-data:www-data * 

# If using NGINX on CentOS:
chown -R nginx:nginx *

# If using Apache on CentOS
chown -R apache:apache *

# 升級 0.7 系列

此版本已終止支援

本文件適用於已終止生命週期的軟體，不再提供任何安全性更新或社群支援。 基於歷史原因，本文件仍保留供查閱。

在正式環境中，你應安裝並使用 Pterodactyl Panel 1.0。

本文件說明的是 0.7.X 系列內部的升級流程，例如從 0.7.3 升級到 0.7.11 這種情境。請不要用本指南從 0.6 升級， 也不要用它升級到 1.0，這兩種情況都有各自專屬的文件。

警告

如果你有使用自訂主題，這裡要提醒一下：升級過程會把這些自訂檔案一併移除。升級完成後記得重新上傳主題檔案， 不然可能會導致伺服器出現錯誤。

# 取得更新檔案

更新流程的第一步，是從 GitHub 下載新的 Panel 檔案。下方指令會下載最新 Pterodactyl 版本的發行壓縮檔，並儲存到 目前目錄。執行前請先確認自己位於 /var/www/pterodactyl，因為下方指令會直接把壓縮檔解到目前所在的資料夾。

警告

由於我們僅提供最新版本文件的翻譯，通常只有依照我們的文件說明操作、或使用我們的一鍵安裝程式，才會套用我們的繁體中文化版本。若你選擇安裝舊版本，即代表你將安裝官方的英文版本，我們將不提供翻譯內容上的支援；但技術問題仍可透過 Discord (opens new window) 與我們聯絡，或與其他使用者討論翻譯相關問題。

curl -L https://github.com/pterodactyl/panel/releases/download/v0.7.19/panel.tar.gz | tar --strip-components=1 -xzv

下載完所有檔案後，還需要幫快取與儲存目錄設定正確的權限，避免之後跑出跟網頁伺服器有關的錯誤。

chmod -R 755 storage/* bootstrap/cache

# 更新相依套件

新檔案都下載完成後，接下來要更新 Panel 的核心元件。執行下方指令，並依照畫面上的提示操作即可。

composer install --no-dev --optimize-autoloader

# 清除已編譯的範本快取

這裡也建議順手清除已編譯的範本快取，這樣使用者才能正確看到新增或修改過的範本內容。

php artisan view:clear
php artisan config:clear

# 更新資料庫

資料庫結構也需要跟著更新，才能配合最新版本的 Pterodactyl。執行下方兩道指令會更新結構，同時確保隨附的預設 Egg 維持在最新狀態，並補上可能新增的 Egg。這裡要特別提醒：千萬不要編輯我們隨附的核心 Egg，因為它們在每次更新過程中 都會被直接覆寫掉。

php artisan migrate --force
php artisan db:seed --force

# 設定權限

最後一步，是把檔案擁有者設定成執行網頁伺服器的那個使用者。大多數情況下會是 www-data，不過實際情況可能因系統 而異，有時候會是 nginx、apache，甚至是 nobody。

# 使用 Nginx 或 Apache（CentOS 除外）：
chown -R www-data:www-data * 

# 在 CentOS 上使用 Nginx：
chown -R nginx:nginx *

# 在 CentOS 上使用 Apache：
chown -R apache:apache *
